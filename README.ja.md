## ⚡ ワンクリックインストール用プロンプト (AI アシスタント向け)

```markdown
この GitHub メタデータ自動注入スキルをインストールして設定してください:
https://github.com/Sacilave/github-info-injector.git
インストール後、現在のプロジェクトを解析し、Description と Topics を自動入力するブラウザコンソール用スクリプトを生成してください。
```

---

## 💡 このツールが必要な理由

GitHub の Web 管理画面には以下の課題があります：
1. **Topics の一括貼り付けに非対応**: カンマ区切りの文字列を貼り付けても、全体が1つの長いタグとして扱われてしまいます。
2. **SEO・GEO に最適化された文章作成の手間**: 説明文に適切なキーワードを含めず、検索エンジンや AI から参照されにくくなります。

**`github-info-injector` はこれらを解消します**:
- プロジェクトを解析し、「**機能優先・形容詞は末尾・140〜180文字**」の洗練された英語の説明文と最大20個のトピックを生成。
- ブラウザの DevTools コンソールに貼り付けて Enter を押すだけで、React の状態を正しく反映しながら一括入力するスクリプトを提供します。
