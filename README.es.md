## 💡 ¿Por qué es necesario este proyecto?

La interfaz web de GitHub presenta dos fricciones habituales:
1. **Sin pegado múltiple de Topics**: Pegar etiquetas separadas por comas crea una sola etiqueta gigante en lugar de dividirlas.
2. **Descripciones poco optimizadas**: A menudo se usan términos genéricos sin palabras clave de entidad útiles para motores de búsqueda o IA generativa.

**`github-info-injector` lo resuelve**:
- Analiza tu código y genera una **descripción en inglés (función primero, adjetivos al final, 140-180 caracteres)** y hasta 20 topics estructurados.
- Produce un script para la consola del navegador que inyecta ambos campos de forma asíncrona en menos de 2 segundos.
